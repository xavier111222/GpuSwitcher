# GPU 切换助手（GpuSwitcher）

一个 **独立单文件** 的 Windows 小工具：在 **NVIDIA 独显** 与 **集显（节能）** 之间一键切换，
并附带重启 / 注销 / 结束占用进程 / 功耗限制 / 系统还原点等配套操作。

- 单文件 exe，绿色免安装，双击即用
- 开源协议：**MIT**
- 仅依赖 Windows 自带的 PowerShell 与 `nvidia-smi`，无需联网

---

## 快速开始

1. 双击桌面上的 **`GPU切换助手.exe`**
2. 首次使用点击右上角 **「获取管理员权限」**（切换显卡必须管理员权限，否则会提示）
3. 点 **「🍃 节能模式」** → 独显被禁用，画面由集显输出，功耗/发热/风扇噪音立刻下降
4. 需要打游戏 / 渲染 / 跑 AI 时点 **「⚡ 高性能模式」** 切回来

> 切换后建议 **注销或重启一次**，才能彻底释放被进程占用的独显。

| 分类 | 功能 | 说明 |

| 切换 | 🍃 节能模式 | 禁用所有 NVIDIA 显示适配器，改用集显 |

| 入口 | 图形性能首选项 | 直接打开 Windows「为应用指定 GPU」设置页 |
| 入口 | NVIDIA 控制面板 / 设备管理器 | 快速跳转 |

## 命令行模式

打包后的 exe 也支持命令行，方便写脚本或放进计划任务：

```bat
GPU切换助手.exe --list                  :: 列出所有显示适配器
GPU切换助手.exe --json                  :: JSON 格式输出
GPU切换助手.exe --apply power           :: 切到节能模式（需管理员）
GPU切换助手.exe --apply performance     :: 切到高性能模式
GPU切换助手.exe --apply power --restart :: 切换后 5 秒重启
```

退出码：`0` 成功 / `1` 部分失败 / `2` 权限不足 / `3` 未检测到 NVIDIA 独显。

## 它是怎么工作的？

不做任何驱动层 hack，只调用 Windows 官方接口：

1. 用 `Get-PnpDevice -Class Display` 枚举显示适配器（PowerShell 的 PnpDevice 模块）
2. 用 `Enable-PnpDevice` / `Disable-PnpDevice` 启用或禁用设备（失败时回退到 `pnputil`）
3. 用 `nvidia-smi` 读取温度 / 功耗 / 显存占用与进程列表

等价于你在设备管理器里手动"禁用设备"，只是自动化了。

---

## ⚠ 注意事项

1. **必须管理员权限**才能启用/禁用设备，程序会自动检测并提示。
2. **MUX 独显直连机型**：如果你的笔记本当前是"独显直连"模式（画面由独显输出），
   禁用独显可能导致 **黑屏**。程序在检测不到集显时会给出警告；
   真出问题时：重启 → 安全模式 → 重新启用，或双击生成的 `恢复显卡（双击运行）.bat`。
3. 禁用独显期间 `nvidia-smi` 不可用，监控面板会显示"独显不可用"，属正常现象。
4. 某些厂商（联想/华硕/戴尔）自带管家软件可能会自动重新启用独显。
5. 第一次运行若被 Windows Defender SmartScreen 拦截，点"更多信息 → 仍要运行"即可（未签名的开源程序常见）。

## 常见问题

**Q：点了节能模式没反应 / 提示失败？**
A：多半是权限不足（程序标题栏应显示"● 管理员"），或有进程仍占用独显。
先去「占用进程」页结束进程，或勾上"切换后自动重启"。

**Q：切换后屏幕闪一下正常吗？**
A：正常，Windows 重建显示拓扑时会闪屏，1-2 秒恢复。

**Q：功耗上限设置失败？**
A：多数笔记本 GPU 的功耗由 EC/厂商固件锁定，`nvidia-smi` 无权修改，属正常限制。

**Q：能不能只让某个程序用独显？**
A：可以，用「Windows 图形性能首选项」按钮打开系统设置，
那里能给单个 exe 指定"高性能/节能"，比全局切换更精细。
